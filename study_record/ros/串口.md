# 串口

### 三、Ubuntu 系统配置（串口识别 + 权限）

#### 步骤 1：确认串口设备路径

插入模块后，两台电脑分别执行以下命令，确认系统识别到串口（路径通常是`/dev/ttyACM0`或`/dev/ttyUSB0`）：

```bash
# 查看串口设备
ls /dev/ttyACM* /dev/ttyUSB*
# 或查看系统日志（确认模块识别）
dmesg | grep -i tty

```

- 若输出`/dev/ttyACM0`，说明识别成功（记录该路径，后续代码 / 工具需用）；
- 若输出为空：检查模块驱动（Ubuntu 默认自带 CH340/CP2102 驱动，缺失则执行`sudo apt install linux-modules-extra-$(uname -r)`），或换 USB 口 / 模块。

#### 步骤 2：配置串口权限（避免访问被拒）

Ubuntu 普通用户默认无串口访问权限，两台电脑均执行：

```bash
# 将当前用户加入dialout组（串口权限组）
sudo usermod -aG dialout $USER
```

### 四、先用串口工具测试连通性（快速验证）

先通过`minicom`/`screen`工具测试链路是否正常，再写代码（避免代码问题干扰硬件排查）。

#### 步骤 1：安装串口工具（两台电脑均执行）

```bash
sudo apt install minicom screen
```

```bash
# 格式：minicom -D 串口路径 -b 波特率（需与B端一致，如9600）
minicom -D /dev/ttyACM0 -b 9600

```

```bash
sudo chmod 777 /dev/usbtt
```
