# 查看话题

## 1. 查看消息类型结构

首先确认你订阅的话题消息类型，比如：

```bash
rostopic type /your_topic
```

然后查看具体字段

```bash
rosmsg show <消息类型>
```

## 2. 用 `rostopic echo` + `grep` 筛选

如果只想看 `orientation` 部分：

```bash
rostopic echo /your_topic | grep orientation -A 4
```

- `-A 4` 表示显示匹配行及其后 4 行。

或者只看 orientation 的 x 值：

```bash
rostopic echo /your_topic | grep "x:"
```
