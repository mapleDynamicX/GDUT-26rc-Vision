- 你构造的 5 个点也严格在 Z=0 平面

平面点的投影模型是：s像素​uv1​​​​=内参K​​外参[r1​​r2​​t​]​​平面3D点​XY1​​​​

这个模型**天生就是共面的**，所以：

### ✅ 共面 = 完全符合数学模型

### ✅ 不共面 = 反而不符合模型，会引入误差

所以你用共面点求解，**数学上是完全自洽、无歧义的**。

# 3. 为什么你构造 5 个共面点不会退化？

PnP 退化的条件是：

**点分布太集中、共线、太少、投影后重叠**

但你满足所有稳定条件：

1. **点数 ≥ 4**（你用了 5 个）
2. **点不共线**（中心 + 上下左右，呈十字分布）
3. **分布均匀、跨度大**
4. **使用平面专用求解器 IPPE**

IPPE 全称：**Infinitesimal Plane-Based Pose Estimation**

它就是为**平面点**设计的，能：

- 唯一确定旋转 R
- 确定到一个**尺度因子**（你代码里就是标签半径）
- 不会出现多解混乱

---

# 4. 真正关键：为什么尺度不会乱？

共面 PnP 确实会有**尺度模糊**

—— 但这**不是问题，反而是你代码的设计核心**。

1. 你用的是**单位半径**的 3D 点
   
   → PnP 解出的 tvec_unit 是**相对尺度**

2. 你已知真实标签物理尺寸 `real_outer_radius`
   
   → 直接乘上去，尺度立刻唯一确定

这就是**平面视觉定位的标准流程**：

- 单应 / 平面 PnP 给出**方向 + 相对距离**
- 物理尺寸给出**绝对尺度**

共面不会影响这个过程，反而保证了：

- 旋转完全正确
- 平移方向完全正确
- 只有尺度未知（而你正好用标签尺寸补上）

# 5. 反过来：如果这些点不共面，会怎样？

如果你的 3D 点 Z≠0，不共面：

所以：

**不共面才是灾难，共面才是正确。**

# 灵魂追问！问到了**单应矩阵最核心的数学盲区**

我直接给你最清晰、最本质的答案：

**你说得完全对：

单应矩阵 H 确实只包含 r₁、r₂、t，没有 r₃，也没有真正的 tz！

那 r₃、tz 到底是怎么 “补” 出来的？**

答案分两层：

1. **r₃ 不是求出来的，是算出来的（旋转矩阵性质）**
2. **tz 不是测量出来的，是 “尺度” 补出来的**

我用**最通俗、最数学、最不绕弯**的方式讲清楚。

---

# 一、r₃ 去哪里了？怎么补回来？

## 先说结论：

**r₃ 不需要从 H 里读！

r₃ 可以直接由 r₁、r₂ 计算得到！**

因为旋转矩阵 **R 必须是标准正交矩阵**，满足：

1. 每一列都是单位向量
2. 列之间互相垂直
3. r₃ = r₁ × r₂ （叉乘）

也就是说：

**只要知道 r₁ 和 r₂，r₃ 是唯一确定的！**

---

## 数学公式（一看就懂）

旋转矩阵结构：

R=[r1​, r2​, r3​]

必须满足：

r3​=r1​×r2​

并且归一化。

---

## 所以：H 里没有 r₃ 完全没关系！

因为：

- **r₁、r₂ 来自 H**
- **r₃ 自动由 r₁ × r₂ 算出**

这就是为什么**单应矩阵虽然只有 8 个自由度，却能恢复完整旋转 R**。

---

# 二、tz 去哪里了？尺度问题怎么解决？

## 结论：

**H 里的 t 是 “带尺度的”，不是真实 tz！

PnP + 真实标签尺寸 = 恢复真正尺度 → 得到真实 tz**

---

## 1. H 里的 t 是：λ t（带尺度因子 λ）

单应矩阵公式：

H=K×[r1​ r2​ t]

但真实公式应该带一个**未知尺度 λ**：

H=K×[r1​ r2​ λt]

这个 λ 就是**尺度歧义**：

- 你不知道 H 里的 t 被放大了多少倍

所以：

**H 无法得到真实距离 tz**

---

## 2. 那代码怎么得到真实 tz？

靠两步：

### ① PnP 解出 “单位尺度” 的 t

代码里：

```cpp
solvePnP(objectPoints_unit, ..., tvec_unit);

```

这里的 3D 点半径 = 1

→ 解出来的 tvec_unit 是 **“多少个标签远”**

### ② 乘以真实物理半径 → 得到真实 tz

```cpp
tvec = tvec_unit * real_outer_radius;

```

这一步就把 **尺度 λ 消除了**

```c
/**
             * @brief 从单个CCTag标记解算真实3D位姿
             * @param marker 有效CCTag对象（必须getStatus()==1）
             * @param cameraMatrix 相机内参矩阵 K (3x3, CV_64F)
             * @param real_outer_radius 标签【真实外圆半径】，单位：米 (如 0.05 代表5cm)
             * @return cctagresult: 结算出的rt
             */
            cctagresult computeCCTagRealPose(const cctag::CCTag& marker, const cv::Mat& cameraMatrix, double real_outer_radius)
            {
                cctagresult result;

                // ===================== 1. 获取单应矩阵 H =====================
                Eigen::Matrix3f H_eigen = marker.homography();
                cv::Mat H = (cv::Mat_<double>(3, 3) <<
                    H_eigen(0,0), H_eigen(0,1), H_eigen(0,2),
                    H_eigen(1,0), H_eigen(1,1), H_eigen(1,2),
                    H_eigen(2,0), H_eigen(2,1), H_eigen(2,2)
                );

                // ===================== 2. 定义【单位尺度】的 3D 世界点 =====================
                // 注意：这里我们假设标签半径为 1.0（归一化单位），暂时不代入真实尺寸
                std::vector<cv::Point3f> objectPoints_unit;
                objectPoints_unit.emplace_back(0.0, 0.0, 0.0);          // 中心
                objectPoints_unit.emplace_back(1.0, 0.0, 0.0);          // 右 (单位半径)
                objectPoints_unit.emplace_back(0.0, 1.0, 0.0);          // 上 (单位半径)
                objectPoints_unit.emplace_back(-1.0, 0.0, 0.0);         // 左 (单位半径)
                objectPoints_unit.emplace_back(0.0, -1.0, 0.0);         // 下 (单位半径)

                // ===================== 3. 利用 H 投影得到对应的 2D 图像点 =====================
                std::vector<cv::Point2f> imagePoints;
                for (const auto& pt3d : objectPoints_unit)
                {
                    cv::Mat p_world = (cv::Mat_<double>(3, 1) << pt3d.x, pt3d.y, 1.0);
                    cv::Mat p_img = H * p_world;
                    double u = p_img.at<double>(0) / p_img.at<double>(2);
                    double v = p_img.at<double>(1) / p_img.at<double>(2);
                    imagePoints.emplace_back(u, v);
                }

                // ===================== 4. 调用 PnP 求解【单位尺度】位姿 =====================
                cv::Mat distCoeffs = cv::Mat::zeros(5, 1, CV_64F);
                cv::Mat rvec, tvec_unit; // 注意：这里的 tvec 是单位尺度的
                
                bool success = cv::solvePnP(
                    objectPoints_unit,
                    imagePoints,
                    cameraMatrix,
                    distCoeffs,
                    rvec,
                    tvec_unit,
                    false,
                    cv::SOLVEPNP_IPPE
                );

                if (!success)
                {
                    result.flag_ = 0;
                    return result;
                }

                result.flag_ = 1;
                result.rvec_ = rvec; // 旋转向量不受尺度影响，直接赋值

                // ===================== 5. 【关键一步】恢复真实物理尺度 =====================
                // tvec_unit 的单位是“标签半径数”
                // 真实 tvec = 单位 tvec * 真实标签半径
                result.tvec_ = tvec_unit * real_outer_radius;

                // 调试输出
                std::cout << "单位尺度距离: " << cv::norm(tvec_unit) << " (R)" << std::endl;
                std::cout << "真实物理距离: " << cv::norm(result.tvec_) << " (m)" << std::endl;

                return result;
            }

```
