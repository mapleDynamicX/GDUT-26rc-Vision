# 配置深度相机头文件

结合你当前的系统环境（Ubuntu 20.04 LTS，代号 `focal`），核心问题是之前添加的 RealSense PPA 源用了错误的版本代号（`jammy`），导致依赖匹配失败。以下是**针对性的解决步骤**，按顺序执行即可：

### 步骤 1：修正 RealSense PPA 源（关键）

先删除错误的源文件，重新添加适配 `focal`（20.04）的官方源：

```bash
# 1. 删除旧的错误源文件
sudo rm -f /etc/apt/sources.list.d/librealsense.list

# 2. 重新添加 GPG 密钥（确保包验证正常）
curl -sSL https://librealsense.intel.com/Debian/librealsense.pgp | sudo gpg --dearmor -o /usr/share/keyrings/librealsense-archive-keyring.gpg

# 3. 添加适配 Ubuntu 20.04 (focal) 的 PPA 源
echo "deb [signed-by=/usr/share/keyrings/librealsense-archive-keyring.gpg] https://librealsense.intel.com/Debian/apt-repo focal main" | sudo tee /etc/apt/sources.list.d/librealsense.list
```

### 步骤 2：清理缓存并刷新源

```bash
# 清理本地缓存（避免残留旧版本信息）
sudo apt clean && sudo apt autoclean

# 重新更新软件包索引（加载正确的 focal 源）
sudo apt update
```

### 步骤 3：安装 librealsense2 及开发包

此时源已适配 20.04，直接安装即可解决依赖问题：

```bash
# 先安装核心库（自动匹配 focal 版本）
sudo apt install -y librealsense2

# 再安装开发包（含 rs.hpp 头文件）
sudo apt install -y librealsense2-dev

# 可选：安装工具包（含 realsense-viewer 可视化工具）
sudo apt install -y librealsense2-utils
```
