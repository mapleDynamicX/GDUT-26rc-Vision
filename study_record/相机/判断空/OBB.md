# OBB

```c
struct Cube {
    std::vector<Eigen::Vector3d> world_corners; // 8个角点（世界坐标系）
    Eigen::Vector3d center;                     // 中心（OBB用）
    Eigen::Vector3d axes[3];                    // OBB正交轴（世界坐标系）
    Eigen::Vector3d extents;                    // OBB半长度（世界坐标系）
};
```

#### 1. `world_corners` - 长方体 8 个角点的世界坐标

- **类型**：`std::vector<Eigen::Vector3d>`，存储 8 个`Eigen::Vector3d`类型的三维向量；

- **含义**：每个元素对应长方体的一个顶点，且所有坐标都基于**世界坐标系**（而非相机 / 局部坐标系）；

- **数量固定为 8**：因为长方体有且仅有 8 个顶点（比如代码中`generateCubeCorners`函数就是生成这 8 个点）；

- **核心用途**：
  
  - 调用`projectWorldToPixel`函数时，将世界坐标的角点投影到像素平面，判断是否在相机视野内；
  - 可视化时绘制长方体的轮廓（比如在图像上标注角点）；
  - 作为 OBB 参数的 “原始数据源”（OBB 的中心 / 轴 / 半长度都是基于这 8 个点计算的）。

#### 2. `center` - OBB 包围盒的几何中心

- **类型**：`Eigen::Vector3d`（三维向量）；

- **含义**：长方体的几何中心（也是 OBB 包围盒的原点），坐标基于世界坐标系；

- **核心用途**：
  
  - 作为 OBB 的 “基准点”，后续计算射线与立方体相交时，会先将射线原点转换到以`center`为原点的局部坐标系，简化计算；
  - 示例中`cube1.center = Eigen::Vector3d(1.0, 0.0, 0.0)`，即立方体 1 的中心在世界坐标系的 (1,0,0) 位置。

#### 3. `axes[3]` - OBB 的三个正交轴

- **类型**：`Eigen::Vector3d`数组（长度为 3）；

- **关键特性**：
  
  - 三个轴**互相正交**（两两垂直）；
  - 每个轴都是**单位向量**（长度为 1）；
  - 轴的方向与长方体的主轴一致（比如无旋转的正方体，axes 就是世界坐标系的 x/y/z 轴：`(1,0,0)、(0,1,0)、(0,0,1)`）；

- **核心用途**：
  
  OBB 的核心优势是 “轴随物体旋转”（区别于 AABB 轴对齐包围盒），这三个轴定义了长方体的姿态。在 Slab 算法中，会沿这三个轴分别计算射线的相交区间，最终判断是否有交集（即是否相交）。

#### 4. `extents` - OBB 的半长度

- **类型**：`Eigen::Vector3d`（三维向量）；

- **含义**：每个分量对应`axes`中对应轴方向上的**半边长**（而非完整边长）；

- **示例**：代码中`cube1.extents = Eigen::Vector3d(0.5, 0.5, 0.5)`，表示：
  
  - 沿`axes[0]`（x 轴）方向的半长度是 0.5 → 完整边长 1；
  
  - 沿`axes[1]`（y 轴）方向的半长度是 0.5 → 完整边长 1；
  
  - 沿`axes[2]`（z 轴）方向的半长度是 0.5 → 完整边长 1；
    
    最终构成边长为 1 的正方体；

- **核心用途**：
  
  定义每个轴方向上的 “有效区间”（`[-extents[i], +extents[i]]`），Slab 算法通过对比射线在每个轴上的区间与该有效区间的交集，判断是否相交。

### 三、OBB vs 传统 AABB（轴对齐包围盒）

| 特性     | AABB（轴对齐包围盒）   | OBB（定向包围盒）        |
| ------ | -------------- | ----------------- |
| 轴的方向   | 固定与世界坐标系对齐     | 随长方体旋转，贴合物体形状     |
| 包围效率   | 差（旋转后包围大量无效空间） | 优（仅包围物体本身）        |
| 计算复杂度  | 低              | 稍高，但 Slab 算法已大幅优化 |
| 遮挡检测精度 | 低（易误判相交）       | 高（贴合物体，减少误判）      |
