# Fast-LIO2

Fast-LIO2 是香港大学 MARS 实验室开源的**轻量级、高性能激光 - 惯性里程计（LIO）** 算法，核心目标是为无人机、地面机器人等移动平台提供**实时、高精度**的位姿估计（位置 + 姿态），是机器人定位导航领域的经典开源项目。

### 1. 核心技术与代码逻辑

Fast-LIO2 的核心是**激光雷达（LiDAR）与 IMU（惯性测量单元）的紧耦合融合**，代码的核心逻辑可概括为：

- **IMU 预积分**：对 IMU 的角速度、加速度数据进行预积分，快速计算位姿增量和协方差，为激光配准提供初始位姿（减少激光配准的计算量）；
- **激光特征提取**：从原始激光点云中提取**平面特征、边缘特征**（而非使用全部点云），大幅降低后续配准的计算成本；
- **点 - 面 ICP 配准**：采用高效的点 - 面迭代最近点（ICP）算法，将激光特征点云与局部地图配准，结合 IMU 约束完成非线性优化，输出最优位姿；
- **多线程优化**：代码中采用多线程处理 “数据接收 - 特征提取 - 位姿优化”，保证实时性（即使在算力有限的嵌入式平台也能运行）。

## 三、成员方法详解

| 方法名                                                                           | 入参 / 出参                | 核心作用                                                                                                                                                                                               |
| ----------------------------------------------------------------------------- | ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 构造函数 `FastLioSamScQn(const ros::NodeHandle &n_private)`                       | 入参：ROS 私有节点句柄          | SLAM 初始化入口：<br><br>1. 加载 ROS 参数（关键帧阈值、体素分辨率、回环参数等）；<br><br>2. 获取功能包路径 / 序列名，初始化 GTSAM 的 ISAM2 优化器；<br><br>3. 初始化回环检测器`loop_closure_`；<br><br>4. 创建 ROS 订阅者、发布者、定时器；<br><br>5. 初始化因子图、初始估计值等核心数据结构。 |
| 析构函数 `~FastLioSamScQn()`                                                      | 无                      | 析构收尾：<br><br>1. 若开启保存标志，将全局地图 / 轨迹保存为 PCD/bag/KITTI 格式；<br><br>2. 释放智能指针资源（日志、内存清理）。                                                                                                               |
| `updateOdomsAndPaths(const PosePcd &pose_pcd_in)`                             | 入参：当前帧位姿 + 点云          | 更新轨迹数据：<br><br>1. 将当前帧位姿添加到原始里程计路径 / 点云；<br><br>2. 若有优化后位姿，同步更新修正后的路径 / 点云；<br><br>3. 加锁保证多线程安全。                                                                                                   |
| `checkIfKeyframe(const PosePcd &pose_pcd_in, const PosePcd &latest_pose_pcd)` | 入参：当前帧、最新关键帧；出参：bool   | 关键帧判断逻辑：<br><br>1. 计算当前帧与最新关键帧的平移 / 旋转差值；<br><br>2. 超过`keyframe_thr_`则返回 true（生成新关键帧），否则返回 false。                                                                                                  |
| `getLoopMarkers(const gtsam::Values &corrected_esti_in)`                      | 入参：优化后位姿；出参：可视化 Marker | 生成回环可视化标记：<br><br>1. 根据`loop_idx_pairs_`获取回环关键帧的优化后位姿；<br><br>2. 生成 ROS Marker（彩色连线），供 RVIZ 展示回环效果。                                                                                                |
| `odomPcdCallback(odom_msg, pcd_msg)`                                          | 入参：同步后的 odom/pcd 消息    | SLAM 核心数据接收回调：<br><br>1. 转换 ROS 消息为`PosePcd`（`current_frame_`）；<br><br>2. 未初始化则完成 SLAM 初始化；<br><br>3. 判断是否生成新关键帧，若是则添加关键帧 + 里程计约束到因子图；<br><br>4. 调用`updateOdomsAndPaths`更新轨迹。                      |
| `saveFlagCallback(const std_msgs::String::ConstPtr &msg)`                     | 入参：保存指令消息              | 接收外部保存指令：<br><br>1. 解析消息（如 "save_map"），设置对应保存标志；<br><br>2. 触发地图 / 轨迹保存逻辑。                                                                                                                          |
| `loopTimerFunc(const ros::TimerEvent &event)`                                 | 入参：定时器事件               | 定时回环检测与图优化：<br><br>1. 调用`loop_closure_`执行回环检测；<br><br>2. 检测到回环则添加回环约束到因子图；<br><br>3. 调用 ISAM2 优化器做增量优化，更新`corrected_esti_`；<br><br>4. 用优化后位姿修正实时位姿`last_corrected_pose_`。                          |
| `visTimerFunc(const ros::TimerEvent &event)`                                  | 入参：定时器事件               | 定时发布可视化数据：<br><br>1. 加锁保护可视化数据，发布原始 / 优化后的路径 / 点云；<br><br>2. 发布全局地图、回环标记；<br><br>3. 广播 TF 变换（map→base_link）。                                                                                       |

### 2. 核心建图相关方法

| 方法名                    | 建图核心作用                                                                                            |
| ---------------------- | ------------------------------------------------------------------------------------------------- |
| `checkIfKeyframe(...)` | 关键帧筛选逻辑：判断当前帧是否满足生成条件，**决定哪些点云能成为建图素材**，是控制建图粒度的核心方法                                              |
| `odomPcdCallback(...)` | 关键帧添加入口：在接收到实时 odom/pcd 后，若判定为新关键帧，会将`current_frame_`加入`keyframes_`，并为其初始化图优化位姿节点，**完成建图素材的持续采集** |

### 2. 核心建图相关方法

| 方法名                    | 建图核心作用                                                                                            |
| ---------------------- | ------------------------------------------------------------------------------------------------- |
| `loopTimerFunc(...)`   | **建图位姿优化的核心执行方法**：定时触发回环检测，生成回环约束并加入因子图，调用 ISAM2 执行增量优化，更新`corrected_esti_`（优化后位姿），为点云拼接提供最新的准确坐标 |
| `odomPcdCallback(...)` | 里程计约束添加：新关键帧生成时，添加**相邻关键帧的里程计约束**到因子图，为图优化提供基础约束，保证局部位姿的合理性                                       |
