# 原子操作

| 访问目标               | 是否可以用 `head_->xxx`？ | 正确做法                                                      |
| ------------------ | ------------------- | --------------------------------------------------------- |
| `std::atomic` 自身成员 | ✅ 可以                | 直接 `head_->load()`/`head_->store(...)` 等                  |
| `Ten_Node<T>` 的成员  | ❌ 不可以               | 先 `auto node = head_->load()`，再 `node.xxx`；修改需通过 CAS 原子操作 |

#### 二、核心原子读写操作

##### 1. `load()`：原子读取值

**函数签名**：

```cpp
T load(std::memory_order order = std::memory_order_seq_cst) const noexcept;
```

**作用**：原子地读取对象当前值，`memory_order` 指定内存序（默认最严格的**顺序一致（seq_cst）**）。

**内存序说明**（简化）：

- `memory_order_relaxed`：仅保证原子性，无内存顺序约束（性能最高）；
- `memory_order_acquire`：禁止后续读 / 写重排到该操作前（“获取” 语义）；
- `memory_order_release`：禁止前面读 / 写重排到该操作后（“释放” 语义）；
- `memory_order_seq_cst`：所有线程看到的操作顺序一致（最安全，性能最差）。

```cpp
#include <atomic>
#include <iostream>

int main() {
    std::atomic<int> a{10};
    // 默认内存序（seq_cst）读取
    int val1 = a.load(); 
    std::cout << val1 << std::endl; // 输出 10

    // 松散内存序（性能更高）读取
    int val2 = a.load(std::memory_order_relaxed);
    return 0;
}
```

##### 2. `store()`：原子写入值

**函数签名**：

```cpp
void store(T desired, std::memory_order order = std::memory_order_seq_cst) noexcept;
```

**作用**：原子地将 `desired` 写入对象，`memory_order` 指定内存序。

**示例**：

```cpp
std::atomic<int> a{0};
// 默认内存序写入 20
a.store(20); 

// 释放内存序写入（配合 acquire 读取实现同步）
a.store(30, std::memory_order_release);
```

## new对象

```cpp
std::atomic<Ten_Node<int>>* head_ = new std::atomic<Ten_Node<int>>();
```

### 错误根源分析

这个错误的核心原因是：**你尝试默认构造 `std::atomic<Ten::Ten_Node<...>>` 对象，但 `std::atomic` 对自定义类型的默认构造函数被显式删除（或不可用）**。

具体拆解：

#### 1. `std::atomic` 默认构造函数的规则

`std::atomic` 的无参默认构造函数（`atomic<T> a;`）并非通用可用：

- **C++11/C++14**：默认构造函数仅创建 “未初始化” 的原子对象，且对于**非平凡类型（如自定义结构体 `Ten_Node`）**，编译器会显式删除该构造函数（避免未初始化导致的未定义行为）；
- **C++17 及以后**：`std::atomic` 的默认构造函数仅当模板参数 `T` 满足「可平凡默认构造（`TriviallyDefaultConstructible`）」时才可用，否则直接删除。

#### 2. `Ten::Ten_Node<T>` 大概率不满足原子类型要求

你的 `Ten_Node` 作为自定义节点类型（比如链表 / 容器节点），通常包含：

- 非平凡构造函数 / 析构函数（比如自定义 `Ten_Node()`、包含 `std::string`/`std::vector` 等非平凡成员）；
- 非平凡复制 / 移动操作；
- 虚函数、指针成员等；

这些特性会导致 `Ten_Node` 不满足 `std::atomic` 对自定义类型的核心要求（**可平凡复制（TriviallyCopyable）+ 可平凡默认构造**），最终触发 `std::atomic` 默认构造函数被删除。
