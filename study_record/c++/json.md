# json

nlohmann/json 是一个**单头文件 header-only**的 C++ JSON 库，无需编译，只需下载并包含`json.hpp`文件即可使用。以下是几种常用的下载方法：

### 方法一：直接下载单个 json.hpp 文件（推荐）

1. 访问官方发布页面：https://github.com/nlohmann/json/releases
2. 选择最新版本（如 v3.12.0），下载`json.hpp`文件（通常在`single_include/nlohmann/`目录下）
3. 或者直接通过这个链接下载最新版本：https://raw.githubusercontent.com/nlohmann/json/master/single_include/nlohmann/json.hpp
4. 将下载的文件放入你的项目目录中，建议创建`nlohmann`子目录存放

### 方法二：下载完整仓库

1. 访问 GitHub 仓库：[GitHub - nlohmann/json: JSON for Modern C++ · GitHub](https://github.com/nlohmann/json)
2. 点击 "Code" 按钮，选择 "Download ZIP" 下载完整源码包
3. 解压后，在`single_include/nlohmann/`目录下找到`json.hpp`文件
