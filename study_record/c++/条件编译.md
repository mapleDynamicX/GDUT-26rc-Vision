# 条件编译

你想了解的是 C/C++ 中的**条件编译预处理指令** `#ifdef`/`#elif`/`#else` 的正确写法，这类指令的核心作用是**根据宏是否被定义**，选择性编译代码段，最终未匹配的代码会在预处理阶段被直接剔除，不会参与编译。

### 核心语法规则

1. 整套条件编译必须以 `#endif` **结尾闭合**，这是必写项，缺失会直接编译报错；
2. `#elif` 是「else if」的预处理缩写，可写**多个**，也可省略；
3. `#else` 是默认分支，最多写**一个**，也可省略；
4. 指令中的 `#` 可以在行首，也可加空格（推荐行首，可读性更高）；
5. 若需在 `#elif` 后检测宏是否定义，需用 `defined(宏名)` （`#ifdef 宏名` 等价于 `#if defined(宏名)`）。

### 完整标准写法（含所有分支）

这是最通用的模板，适配多条件宏判断场景，直接套用即可：

```cpp
// 第一步：检测宏1是否被定义（#define 宏1  即可，有无值都不影响#ifdef判断）
#ifdef 宏名1
    // 分支1：宏1被定义时，编译这部分代码
    代码段1;

// 第二步：多条件判断（可写多个#elif，按需增加）
#elif defined(宏名2)  // 检测宏2是否被定义（核心写法）
    // 分支2：宏1未定义、宏2被定义时，编译这部分代码
    代码段2;

#elif defined(宏名3) && 宏名3 == 2  // 进阶：检测宏定义+判断宏的值
    // 分支3：宏1/2未定义、宏3被定义且值为2时，编译这部分代码
    代码段3;

// 第三步：默认分支（可选，无匹配时执行）
#else
    // 分支4：以上宏都未定义时，编译这部分代码
    代码段4;

// 关键：闭合条件编译，不可省略
#endif
```

```c
cmake_minimum_required(VERSION 3.10)
project(MyDemo CXX)
set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# 核心：全局定义宏，和g++ -D语法一模一样！
add_definitions(
    -DIS_LINUX
    -DMY_DEBUG
    -DLOG_LEVEL=2
    -DMAX_NUM=100
    -DVERSION=\"v1.0.0\"
    -DAUTHOR=\"ubuntu\"
)

add_executable(main main.cpp) # 建目标放在宏定义后也可以
```

## 总结（纯手动定义宏的核心要点）

1. 优先用 **`target_compile_definitions(目标名 PRIVATE 宏)`**，现代 CMake 标准，不全局污染；
2. 宏分 3 种写法：无值（`A`）、数字值（`A=2`）、字符串（`A=\"str\"`），**字符串必须转义双引号**；
3. 简易场景用`add_definitions(-D宏)`，语法和`g++ -D`完全一致，全局生效；
4. 必须先执行`add_executable`创建目标，再用推荐写法定义宏（顺序别搞反）；
5. 动态改宏不用动 CMakeLists.txt，`cmake .. -D宏=值`即可。
