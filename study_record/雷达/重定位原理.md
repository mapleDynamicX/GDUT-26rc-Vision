# 重定位原理

## TEASER++

## 1. 算法核心思想

TEASER++ 采用**截断最小二乘 (TLS)**代价函数重新建模配准问题，使估计对大量错误对应不敏感。通过**图论框架**将尺度、旋转和平移估计解耦，实现级联求解，同时利用 ** 渐进非凸性 (GNC)**优化旋转估计并通过**Douglas-Rachford Splitting (DRS)** 证明全局最优性。

## 2. 数学基础与问题建模

### 2.1 点云配准问题

给定两组 3D 点云对应关系{(ai​,bi​)}i=1N​，寻找最优变换参数(s,R,t)，使：

bi​≈sRai​+t+ϵi​(i=1,2,...,N)

其中：s为尺度，R∈SO(3)为旋转矩阵，t∈R3为平移向量，ϵi​为噪声。

### 2.2 截断最小二乘 (TLS) 代价函数

传统最小二乘法对异常值敏感，TEASER++ 采用**截断最小二乘**：

mins,R,t​∑i=1N​min(βi2​∥bi​−sRai​−t∥2​,cˉ2)

其中：βi​是噪声上界，cˉ2是截断阈值。当残差超过cˉβi​时，仅计入固定值cˉ2βi2​，从而降低异常值影响。

## 3. 算法框架：解耦估计策略

TEASER++ 采用**级联解耦策略**，依次估计尺度、旋转和平移：

1. **尺度估计**：利用**平移和旋转不变测量 (TRIM)**
2. **旋转估计**：使用**GNC-TLS**优化方法 (替代 TEASER 的 SDP 松弛)
3. **平移估计**：基于**分量独立的 TLS**估计

这种解耦使每个子问题更易处理，同时保持全局最优性证明的可行性。

## 4. 关键技术详解

### 4.1 尺度估计：自适应投票机制

**Step 1: 构建 TRIM 测量**

对每对点对(i,j)，计算：

- 平移不变向量：aˉij​=aj​−ai​,bˉij​=bj​−bi​
- 尺度测量：sij​=∥aˉij​∥∥bˉij​∥​
- 噪声边界：αij​=∥aˉij​∥βi​+βj​​

**Step 2: 自适应投票求解**

将问题转化为寻找s^，使满足∣sij​−s^∣≤cˉαij​的点对最多。通过**自适应投票**高效求解：

1. 生成候选尺度集合 (基于所有sij​)
2. 对每个候选尺度，确定一致点对集合
3. 选择支持度最高的尺度作为s^

### 4.2 旋转估计：GNC-TLS 方法

**传统 TEASER 的局限**：使用 SDP 松弛求解旋转，计算复杂度高。

**TEASER++ 创新**：采用 ** 渐进非凸性 (GNC)** 优化方法，避免 SDP 求解，同时保持可证明性。

**GNC 核心思想**：从高度凸化的目标函数开始，逐步增加非凸性，引导优化跳出局部最优，最终收敛到全局最优。

**GNC-TLS 旋转估计步骤**：

1. 基于估计的尺度s^，构建旋转不变测量 (TIM)：aˉij​→s^Raˉij​≈bˉij​

2. 定义旋转优化问题：
   
   R^=R∈SO(3)argmin​∑k=1K​min(δk2​∥bˉk​−s^Raˉk​∥2​,cˉ2)

3. **GNC 优化过程**：
   
   - 引入控制参数μ>0，初始值较大 (高度凸化)
   
   - 求解凸化问题：R^μ​=R∈SO(3)argmin​∑ρμ​(∥bˉk​−s^Raˉk​∥2)
   
   - 其中ρμ​(z)={z/δk2​,cˉ2+μ(z−cˉ2δk2​),​z≤cˉ2δk2​z>cˉ2δk2​​
   
   - 逐步减小μ(增加非凸性)，重复求解，直到收敛

### 4.3 全局最优性证明：DRS 方法

**挑战**：GNC 作为启发式方法，需证明其解的全局最优性。

**TEASER++ 解决方案**：利用**Douglas-Rachford Splitting(DRS)**设计高效的**全局最优性验证算子**。

**DRS 核心思想**：将复杂的凸可行性问题分解为简单的子问题求解，特别适合高维空间中的投影操作。

**验证步骤**：

1. 计算候选解R^的**次优性间隙**：μ=gap(R^)

2. 若μ≤0，则R^是全局最优解

3. 若μ>0，则R^不是最优，但可给出误差上界

### 4.4 内点筛选：最大团算法

**问题**：即使有 TLS 保护，仍需进一步剔除异常值。

**解决方案**：构建**内点一致性图**，寻找**最大团**(全连接子图)，确保选中的点对都满足同一变换。

**具体步骤**：

1. 基于估计的尺度s^，定义点对(i,j)和(k,l)的兼容性：
   
   comp((i,j),(k,l))={1,0,​if ∥sij​−skl​∥≤cˉ(αij​+αkl​)otherwise​

2. 构建图：顶点为点对，边表示兼容性

3. 寻找**最大团**(所有顶点互相连接的最大子图)，对应最一致的点对集合

4. 仅用最大团中的点对进行后续旋转和平移估计

### 4.5 平移估计：分量独立 TLS

**方法**：在已知尺度s^和旋转R^后，平移估计可分解为三个独立的标量问题：

对每个坐标轴j∈{1,2,3}：

t^j​=tj​argmin​∑i=1N​min(βi2​(tj​−[bi​−s^R^ai​]j​)2​,cˉ2)

**求解**：使用与尺度估计相同的**自适应投票**方法，高效求解每个分量。

## 5. TEASER++ 完整算法流程

1. **输入**：点云对应{(ai​,bi​)}，噪声上界{βi​}，截断阈值cˉ2

2. **尺度估计**：
   
   - 计算 TRIM 测量{sij​,αij​}
   - 使用自适应投票估计s^
   - 构建内点图，寻找最大团，筛选可靠点对

3. **旋转估计**：
   
   - 基于s^和筛选后的点对，构建 TIM
   - 使用 GNC-TLS 优化求解R^
   - 用 DRS 验证R^的全局最优性

4. **平移估计**：
   
   - 对每个坐标轴，使用自适应投票估计t^j​

5. **输出**：变换参数(s^,R^,t^)，以及内点集合

## 6. 算法优势与创新

| 特性         | TEASER++ 实现方式      | 优势                          |
| ---------- | ------------------ | --------------------------- |
| **异常值鲁棒性** | 截断最小二乘 + 最大团筛选     | 可处理 99% 异常值，远超 RANSAC 等传统方法 |
| **计算效率**   | GNC 替代 SDP + 并行化实现 | 毫秒级运行，适合实时应用                |
| **全局最优性**  | GNC+DRS 验证         | 提供可证明的解质量保证，无需依赖初始猜测        |
| **解耦策略**   | 尺度→旋转→平移级联求解       | 每个子问题更简单，减少全局搜索空间           |

## 7. 总结

TEASER++ 通过**截断最小二乘**代价函数、**解耦估计**策略、**GNC 优化**和**DRS 验证**，实现了**高效且可证明**的点云配准，在异常值处理能力和计算效率间取得了突破。

该算法已广泛应用于机器人导航、3D 重建、自动驾驶等领域，是目前处理高噪声点云配准的首选算法之一。若需更深入理解其实现细节，建议参考 MIT 开源的 C++/Python 实现 (https://github.com/MIT-SPARK/TEASER-plusplus)。

## Eigen旋转矩阵转欧拉角

```cpp
#include <Eigen/Dense>
#include <cmath>

// 定义浮点数精度阈值，用于判断浮点数是否接近0
const double EPS = 1e-6;

/**
 * @brief Eigen旋转矩阵转欧拉角（Z-Y-X 顺序：Yaw-Pitch-Roll）
 * @param R 3x3 Eigen旋转矩阵
 * @param roll 输出：横滚角（绕X轴），弧度
 * @param pitch 输出：俯仰角（绕Y轴），弧度
 * @param yaw 输出：偏航角（绕Z轴），弧度
 */
void rotationMatrixToEulerAngles(const Eigen::Matrix3d& R, double& roll, double& pitch, double& yaw) {
    // 从旋转矩阵(2,0)位置提取-sin(pitch)，取负后得到sin(pitch)
    double sin_pitch = -R(2, 0);

    // 钳位sin_pitch到[-1,1]区间，避免因浮点数误差导致asin输入非法
    sin_pitch = std::max(std::min(sin_pitch, 1.0), -1.0);

    // 通过反正弦计算俯仰角，范围[-π/2, π/2]
    pitch = std::asin(sin_pitch);

    // 计算俯仰角的余弦值，用于后续万向节锁判断和roll/yaw计算
    double cos_pitch = std::cos(pitch);

    // 判断是否进入万向节锁（cos_pitch≈0即pitch≈±90°）
    if (std::abs(cos_pitch) > EPS) {
        // 无万向节锁时，计算横滚角：atan2(R(2,1)/cos_pitch, R(2,2)/cos_pitch)
        roll = std::atan2(R(2, 1), R(2, 2));
        // 无万向节锁时，计算偏航角：atan2(R(1,0)/cos_pitch, R(0,0)/cos_pitch)
        yaw = std::atan2(R(1, 0), R(0, 0));
    } else {
        // 万向节锁下，固定偏航角为0（消除自由度耦合）
        yaw = 0.0;
        // 俯仰角接近+90°时的横滚角计算
        if (pitch > 0) {
            roll = std::atan2(-R(0, 1), R(0, 2));
        } 
        // 俯仰角接近-90°时的横滚角计算
        else {
            roll = std::atan2(R(0, 1), -R(0, 2));
        }
    }
}

// 测试示例（可选）
int main() {
    // 构造测试旋转矩阵：绕Z轴转π/4，Y轴转π/6，X轴转π/3
    Eigen::Matrix3d R = Eigen::AngleAxisd(M_PI/4, Eigen::Vector3d::Z())
                      * Eigen::AngleAxisd(M_PI/6, Eigen::Vector3d::Y())
                      * Eigen::AngleAxisd(M_PI/3, Eigen::Vector3d::X());

    double roll, pitch, yaw;
    // 调用函数转换旋转矩阵到欧拉角
    rotationMatrixToEulerAngles(R, roll, pitch, yaw);

    // 输出结果（弧度）
    printf("Roll: %.4f, Pitch: %.4f, Yaw: %.4f\n", roll, pitch, yaw);

    return 0;
}
```
